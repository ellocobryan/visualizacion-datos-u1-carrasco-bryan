## Definición
Proceso sistemático de reunir y medir información de diversas fuentes (encuestas, sensores, APIs, web scraping, registros transaccionales) para responder preguntas analíticas.

## Resumen Personal
Es el primer paso práctico del pipeline de datos. Define el alcance y los límites de lo que se podrá analizar posteriormente.

## Importancia
Asegura que los datos capturados sean representativos y suficientes para abordar el problema de negocio planteado.
